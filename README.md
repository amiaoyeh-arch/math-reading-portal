## 🎯 教學核心：數學讀題「三色透視讀題法」

為了解決國小學生面對長篇應用題時「抓不到重點」、「漏看關鍵條件」或「算到一半忘記求什麼」的痛點，本專案依據提示詞與讀題工程三大核心要素，建立專屬的色彩透視導學鷹架：

| 要素名稱 | 視覺色彩 | 定義與在數學解題中的功能 |
| :--- | :--- | :--- |
| **🌿 背景語句 (Context)** | **淺青綠底**（#DCFCE7） | 提供事件情境、人物角色、生活前因後果，引導學生進入情境、縮小理解範圍。 |
| **🌟 條件語句 (Conditions)** | **明亮黃底**（#FEF08A） | 包含已知數據、限制規則、倍數關係、增減變化等，是**解題列式最核心的算式骨幹**。 |
| **🎯 核心問題 (Core Question)** | **珊瑚粉紅底**（#FFE4E6） | 明確指出題目「要算什麼」、要達成的最終任務，決定計算方向與出口。 |

## 🏫 各年級收錄試題與教材模組

### 1. 📘 [三年級全卷導學簡報 (grade3.html)](grade3.html)
* **收錄範圍**：115 年度 新北市國小學習能力檢測 · 三年級數學科（全卷 25 題）
* **核心重點**：除法算式意義、圖形週期規律、四位數減法、容量公升毫升換算、正方形角特徵、分數等值、數線左右跳躍、圓規作圖。

### 2. 📗 [四年級全卷導學簡報 (grade4.html)](grade4.html)
* **收錄範圍**：115 年度 新北市國小學習能力檢測 · 四年級數學科（全卷 25 題）
* **核心重點**：二位小數比較、雙條件菜單交叉篩選、乘法分配律拆數、烘焙時程倒推、三角板拼角、直線垂直平行、折線圖走勢、全等三角形。

### 3. 📙 [五年級關係(R)導學簡報 (grade5.html)](grade5.html)

### 4. 📕 [六年級數與量(N)導學簡報 (grade6.html)](grade6.html)
* **收錄範圍**：114 年度 新北市國小學習能力檢測 · 六年級「數與量 (N)」主題 17 題
* **核心重點**：複雜分數分配律、正反比份量、公頃公畝面積換算、小數除法汽油單價、連除性質、最大公因數短除法、工作率與工程問題、基準量與比較量、速率單位換算。
